# UpewnieniePlikow krótki opis
Program **UpewnieniePlikow** działa na systemach **MacOS** **Windows** czy **Linux**. (Uwaga! Plik Należy skomplikować ręcznie).
Program **UpewnieniePlikow** służy do zamiany nazw plików na ich sumę kontrolną **SHA-256**.
Program **UpewnieniePlikow** jest napisany w **100%** w języku C. Dodatkowo program jest samowystarczalny i nie korzysta z **żadnych bibliotek**.
# Działanie programu
Program działa w terminalu, dodatkowo należy wpisać/wkleić ścieżkę do folderu z plikami, a program automatycznie zamieni ich nazwy.
